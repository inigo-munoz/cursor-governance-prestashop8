# `tests/scenarios/`

Este directorio contendrá **escenarios de test** que describen qué fixtures se
usan y qué comprobaciones de gobernanza deben ejecutarse sobre ellos.

Por ahora solo es un placeholder mínimo. Más adelante se añadirán aquí ficheros
estructurados (por ejemplo, YAML) que indiquen:

- Qué fixture de `tests/fixtures/` se está probando.
- Qué skills de `skills/` deben ejecutarse.
- Qué checklists de `checklists/` deben aplicarse.
