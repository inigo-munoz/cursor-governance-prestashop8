# `tests/expectations/`

Este directorio contendrá los **resultados esperados** para cada escenario de
test de gobernanza.

Por ahora solo es un placeholder mínimo. En el futuro se añadirán aquí ficheros
estructurados (por ejemplo, YAML) que describan:

- Qué hallazgos deberían producir las skills y checklists para un escenario
  concreto.
- Qué pasos de checklist deben marcarse como OK, WARNING o FAIL.
